## What Was Done

### 1. Domain Model Layer Created
- **File**: `internal/domain/models.go` (NEW)
- Pure business entities: `TimeLog`, `Category`, `CategoryNode`, `Task`, `Constraint`, `Metric`, `MetricRecord`, `PasskeyCredential`, `TempPassword`
- Zero dependencies on GORM, protobuf, or any persistence/transport concern
- Methods like `TimeLog.Duration()`, `TimeLog.IsOngoing()`, `PasskeyCredential.ToCredential()`

### 2. Ports Decoupled from model/gen
- **File**: `internal/ports/ports.go`
- All Repository interfaces now use `domain.*` types instead of `gen.*` types
- `PasskeyCredentialRepository` uses `domain.PasskeyCredential` instead of `model.WebAuthnCredential`
- `TempPasswordRepository` uses `domain.TempPassword` instead of `model.TempPassword`

### 3. Adapters Rewritten as Converters
- **File**: `internal/adapter/mapper.go` (NEW) — 580+ lines of bidirectional mapping
- All adapter implementations (`timelog.go`, `task.go`, `category.go`, `constraint.go`, `metric.go`, `passkey.go`, `temp_password.go`) now:
  - Accept `domain.*` from service layer
  - Convert to `gen.*` / `model.*` for persistence layer
  - Return `domain.*` back to service layer
- `internal/adapter/repository.go` and `unit_of_work.go` updated for new constructor names

### 4. Service Layer Migrated to Domain Types
- **Files**: `service/timelog.go`, `service/task.go`, `service/constraint.go`, `service/metric.go`, `service/passkey.go`, `service/timelog_mcp.go`, `service/webauthn_user.go`
- All method signatures use `domain.*` types
- `service/service.go` constructor unchanged (already accepted ports interfaces)
- Helper `passkeyCredentialToWebAuthn()` added in `webauthn_user.go` (domain → webauthn.Credential)

### 5. Router & MCP Updated
- **Files**: `router/timelog.go`, `router/task.go`, `router/category.go`, `router/constraint.go`, `router/metric.go`, `mcp/handlers.go`
- Removed all `model/gen` imports
- Adjusted for value types (e.g., `tl.ID` instead of `*tl.ID` since domain types use plain `int32`)

### 6. API Mapper Layer Rewritten
- **Files**: `internal/api/mapper/*.go`
- All mapper functions now map between `domain.*` ↔ `timelogv1.*` (protobuf types)
- Tests updated accordingly
- `auth.go` now maps `domain.PasskeyCredential` to proto

### 7. Tests Updated
- `service/metric_test.go`, `service/timelog_mcp_test.go`, `service/task_filter_test.go`
- `service/timelog_query_test.go` — still uses `gen.Timelog` for seeding (acceptable, it's bypassing domain layer for DB setup)
- `test/category_tree_test.go` — uses `domain.Category`
- `internal/api/mapper/*_test.go` — all updated for domain types

## Known Edge Cases

1. **`model/gen/metrics.gen.go`** was manually written because GORM gen didn't generate Metric/MetricRecord types. The file was missing from the original repo (not in gitignore, just never generated). The manual version is at `model/gen/metrics.gen.go`.

2. **webauthn type mapping** — `domain.PasskeyCredential` stores `Transport` as `string` (serialized from `[]protocol.AuthenticatorTransport`). Conversion helpers are in `service/webauthn_user.go` and `internal/adapter/mapper.go`.

3. **`CategoryNode` in domain** — `domain.CategoryNode` uses `Category Category` (value type) while `model.CategoryNode` uses `Category gen.Category` (value type). The adapter conversion handles this.

4. **Router changes** — Many `*gen.Timelog.ID` → `domain.TimeLog.ID` (pointer to value) changes. The routers were updated but double-check `timelog.go`, `category.go` for `&id` → `id` assignments.
